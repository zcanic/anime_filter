## 关键测试场景

### 撤销功能
测试了完整的撤销工作流程：
1. 用户标记动漫为"interested"
2. 更新为"watched"
3. 撤销（删除最新操作）回到"interested"
4. 再次撤销回到未审核状态

### 缓存一致性
验证了：
1. 保存操作后缓存立即更新
2. 删除操作后缓存立即更新
3. 重启后缓存正确从数据库加载
4. 缓存统计与数据库统计一致

### 批量操作
测试了：
1. 空批量操作（无错误）
2. 大量批量操作（1000个项目）
3. 批量操作中的部分更新
4. 批量操作后的选择性撤销

### 并发安全性
验证了：
1. 多个线程访问同一单例
2. 不同主题的并发保存
3. 线程本地数据库连接

## 发现的潜在问题

### 1. 时间戳生成警告
- 使用`datetime.utcnow()`已被弃用
- 建议改用`datetime.now(datetime.UTC)`

### 2. 线程初始化问题
- 多线程同时初始化Database实例会导致连接问题
- 实际使用中不会发生（单例只初始化一次）

### 3. Pydantic配置弃用警告
- 使用类式`config`已被弃用
- 建议改用`ConfigDict`

## 测试运行

### 快速运行
```bash
cd backend
source venv/bin/activate
export PYTHONPATH=$PYTHONPATH:$(pwd)/..
python -m pytest tests/ -v
```

### 使用测试脚本
```bash
cd backend
./run_tests.sh
```

### 特定测试集
```bash
# 仅数据库测试
python -m pytest tests/test_database_comprehensive.py -v

# 仅服务测试
python -m pytest tests/test_service_and_api_comprehensive.py::TestAnimeServiceUnit -v

# 仅API测试
python -m pytest tests/test_service_and_api_comprehensive.py::TestAPIIntegration -v
```
