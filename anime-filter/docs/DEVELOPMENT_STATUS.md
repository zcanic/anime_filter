## 📊 项目概览

AnimePick 是一款基于 Tauri 2 + React + Python FastAPI 构建的桌面动漫筛选应用，配备先进的 TF-IDF 推荐引擎。

### 推荐系统 (v0.3.0)

#### 后端实现 ✅

- ✅ **TF-IDF 特征工程**
  - 14,256 部动漫向量化
  - 1000 维 TF-IDF 特征
  - 稀疏存储（~1.4MB）
  - Tag 分类和权重分配

- ✅ **推荐引擎核心**
  - 三组件融合算法（全局 40% + 局部 40% + 多样性 20%）
  - 滞后响应机制（lag_steps=1）
  - Temperature 调节（T=2.0）
  - 向量化批量计算（300倍性能提升）

- ✅ **Session 管理**
  - Session 创建和持久化
  - 滑动窗口历史（window_size=50）
  - 自动过期清理（24小时）

- ✅ **API 端点**
  - `GET /api/anime/list?sort_by=recommended&session_id=xxx`
  - 自动 session 追踪（X-Session-ID header）
  - 降级处理（无历史时）

- ✅ **性能优化**
  - 优化前：~20秒/请求（逐个计算）
  - 优化后：~66ms/请求（向量化）
  - 内存占用：~1.4MB

- ✅ **测试覆盖**

  - 推荐质量检查

## 🐛 已知问题

### 推荐系统

1. **冷启动问题**
   - **问题**: 首次使用需至少观看 2 部动漫才能获得推荐
   - **影响**: 新用户体验略差
   - **缓解**: 可考虑基于热度的默认推荐
   - **优先级**: 中

2. **Session 跨设备不同步**
   - **问题**: Session ID 存储在本地，不同设备推荐不一致
   - **影响**: 多设备用户体验受限
   - **缓解**: 预期行为，未来可加用户系统
   - **优先级**: 低

### 性能

3. **内存占用可能随规模增长**
   - **问题**: 全量特征向量加载到内存
   - **影响**: 对于 14K 动漫可接受，百万级需优化
   - **缓解**: 考虑分片加载或按需加载
   - **优先级**: 低

### 测试

4. **并发测试 SQLite 锁定**
   - **问题**: pytest 并发运行时可能文件锁定
   - **影响**: 测试速度慢
   - **缓解**: 使用 `-n 1` 单线程运行
   - **优先级**: 低
